# HuntTally
モブ討伐数記録プラグイン

## プラグイン概要
このプラグインはモブの討伐数を記録するプラグインです。  
日本語クライアントのみで動作します。  

* `/hunttally`コマンドでウィンドウを開閉
    * ウィンドウの表示状態を記録し自動復元
* モブ討伐数を自動記録
* モブ名でフィルター可能
